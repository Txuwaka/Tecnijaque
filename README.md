# Tecni Jaque

Cada jugada, una historia.

Creado por Txuwa, con la ayuda de Astra.

## Jugar

Sirve el contenido de esta carpeta por HTTP/HTTPS, por ejemplo con `python3 -m http.server 8000`, y abre http://localhost:8000. Para actualizar tu web, sustituye los archivos por los de este ZIP.

Tablero 2D y 3D, cuatro dificultades, consejos de Nox, melodía y río con controles independientes. El menú reúne los ajustes; los accesos de audio y pantalla completa están en la cabecera. La partida se guarda en el navegador.
